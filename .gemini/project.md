# Projektziel: Online Lebenslauf ("About Me")

Dieses Projekt dient dem Aufbau eines dynamischen, "lebendigen" Online-Lebenslaufs. 
Die Webseite wird als Statische Webseite über IONOS Deploy-Now bereitgestellt, gesteuert über einen GitHub Actions Workflow (`.github/workflows/deploy-now.yml`).

## Lernziele des Nutzers
- Evaluierung und Anwendung von **Svelte** (Fokus auf moderne Versionen ab Svelte 5).
- Einsatz und Lernen von **Vite** als Build-Tool und Entwicklungsserver (ab Vite 5).
- Allgemeines Auffrischen des ursprünglichen Projekt-Setups.

## Technologie-Stack
- **Framework:** Svelte
- **Build Tool:** Vite
- **Sprache:** TypeScript
- **Styling:** SCSS (`sass`), Bootstrap (via `sveltestrap`)
- **Hosting:** IONOS Deploy-Now
